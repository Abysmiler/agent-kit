## 覆盖原则

### 从系统结果出发

从用户、运维人员、业务/使命目标、关键工作流、核心资产数据（crown-jewel data）、特权操作与代价高昂的失败模式开始。代码结构是证据，不是风险的定义。

### 显式审计质量属性

至少对以下各项排序：

- 正确性。
- 安全与隐私。
- 可靠性与可恢复性。
- 可修改性与可维护性。
- 性能与容量。
- 可运维性与可观测性。
- 相关场景下的可移植性/互操作性。
- 成本。

一个设计对某一属性合理，可能对另一属性有害。记录权衡，而不是抽象地宣布架构"好"或"坏"。

### 组合覆盖来源

可信的周期审计组合：

- 画像规定的常开面。
- 已变更与高变动区域。
- 依赖失效锥。
- 轮换深切片。
- 事故、逃逸缺陷、不稳定检查与运维痛点。
- 未关闭的发现与已接受的技术债。
- 跨子系统边界的端到端场景。

### 区分发现与缺口

- `finding`（发现）有缺陷、控制弱点或有界结构性风险的证据。
- `gap`（缺口）表示证据不足以得出结论。
- `No Action` 表示就已批准的画像与可得证据而言，被评审区域是合理的。

不要把每个未知都转成缺陷，也不要把每次干净的扫描都转成安全证明。

## 治理、情境与风险框架

评审：

- 系统/工作负载边界及被排除的相邻系统。
- 主要用户、运维人员、所有者、数据管理员、安全联系人与决策授权人。
- 业务/使命目标与关键工作流。
- 核心资产数据、密钥、资金、授权权益、特权操作与不可逆操作。
- 外部系统、处理方、供应商与契约依赖。
- 法律、隐私、监管、行业与客户义务。
- 风险偏好、显式非目标、已接受风险与升级规则。
- 事故历史、险情、滥用报告、支持升级与运维痛点。
- 资产清单与数据分类。
- 威胁行为者与现实的滥用案例。
- 安全开发归属、漏洞披露、分诊、修复与例外流程。
- 审计画像的批准、新鲜度与变更控制。

证据可包括画像、架构文档、合同、威胁模型、数据地图、事故报告、服务目录、归属文件与访谈。当期望 agent 独立运作时，将仓库中不可见的隐性知识标记为可维护性与 agent 可读性风险。

## 架构与质量属性

评审：

- 域/模块边界、归属、依赖方向与扩展点。
- 公开 API、事件、schema、契约、版本管理与兼容性策略。
- 架构决策，以及代码、ADR、图与运行时拓扑是否一致。
- 集中式与分布式的状态归属。
- 耦合、内聚、循环依赖、上帝模块、服务蔓延与横切关注点入口。
- 故障隔离、爆炸半径边界、多租户隔离与权限分离。
- 同步/异步选择与一致性权衡。
- 自建还是外购的决策与不透明依赖。
- 可移植性与环境特定假设。
- 演进压力：可能的下一个功能、规模变化、监管与集成。
- 架构适应度函数或结构性测试。
- 生成的架构地图及其来源/更新路径。

对重大决策使用质量属性场景：

- **刺激（Stimulus）：** 变更、失败、负载、攻击、运维操作或新需求。
- **环境（Environment）：** 正常、降级、峰值、滚动部署、局部中断或恢复。
- **工件（Artifact）：** 受影响的服务/模块/数据流。
- **响应（Response）：** 预期行为。
- **度量（Measure）：** 延迟、错误率、恢复时间、受影响租户、变更成本或证据。
- **权衡（Tradeoff）：** 什么变好，什么变差。

依据场景而非图表美观度来审计架构。

## 业务正确性与关键工作流

评审：

- 端到端的关键用户与运维旅程。
- 领域不变量与合法状态转换。
- 涉及资金、单位、日期、时区、配额、排序、资格或权益的计算。
- 默认值、缺失数据、空状态、最大/最小值、非法转换与遗留记录。
- 错误、取消、重试、超时与部分完成行为。
- 向后兼容与混合版本行为。
- 导入/导出与外部契约保真。
- 幂等与重复请求。
- 源系统、账本、缓存与派生视图之间的对账。
- 人工覆盖、审计追踪、申诉、回滚与更正路径。
- 改变语义的特性开关与实验。
- 产品规格漂移，以及只存在于代码或人们头脑中的规则。
- 可绕过正常校验的运维工具。

从入口校验、领域逻辑、持久化、副作用到用户可见结果，逐条追踪关键不变量。局部正确的函数不能证明整个工作流。

## 身份、访问、安全与隐私

### 身份与会话

评审：

- 认证机制、账户找回、MFA、注册与凭据生命周期。
- 会话创建、轮换、吊销、过期、固定、重放与设备/会话可见性。
- 服务间身份、工作负载身份、证书/令牌签发与轮换。
- 独立的 agent/服务身份与共享的开发者凭据。

### 授权与隔离

评审：

- 对象级与动作级授权。
- 租户、组织、项目、账户与用户隔离。
- 角色/权限模型、提权、委托、代理与紧急破窗（break-glass）访问。
- 后台任务、缓存、导出、webhook 与管理工具中的授权。
- 集中式策略执行与绕过路径。
- 默认拒绝行为与 fail-open 条件。

### 输入、输出与执行

评审：

- 信任边界处的校验。
- 注入：SQL/NoSQL、shell、模板、路径、头部、表达式、查询语言、反序列化与代码执行。
- SSRF、URL 抓取、重定向、DNS/内网访问与 webhook 校验。
- 文件上传/下载、路径穿越、压缩包、符号链接、媒体处理与不安全的服务方式。
- 输出编码、XSS、内容安全策略与不可信的富文本/Markdown。
- 加密使用、密钥存储、nonce/IV 行为、随机性、签名与验证。
- 动态插件/模块加载与扩展点。

### 密钥与敏感数据

评审：

- 密钥存储、范围、轮换、吊销，以及通过日志/错误/遥测/构建产物/前端包的暴露。
- 数据最小化、目的限制、同意、留存、删除、导出与驻留。
- 传输中/静态加密与密钥管理边界。
- 开发、CI、agent、分析与支持工具对生产数据的访问。
- 备份、快照、崩溃转储、对话记录与临时文件。
- 审计日志与防篡改能力。

### 滥用与韧性

评审：

- 速率限制、配额、枚举、爬取、欺诈、垃圾信息、拒绝服务与高代价操作。
- 滥用案例测试与监控。
- 漏洞披露、依赖响应、事故响应与补丁部署。
- 威胁模型新鲜度，以及安全需求到实现/测试的追踪。

每条安全发现都要锚定到资产、信任边界、攻击者能力、可达性与影响。

## 数据生命周期与持久化

评审：

- 数据模型、schema 归属、约束、索引、默认值、可空性与引用完整性。
- 迁移设计、锁、回填、在线兼容、回滚与灾难恢复。
- 事务、隔离级别、一致性、丢失更新、写偏斜与部分写入。
- 缓存键、失效、脏数据、一致性与租户范围。
- 事件 schema、版本、排序、去重、重放与死信处理。
- 派生状态、物化视图、搜索索引、分析与对账。
- 序列化格式、精度、编码、时区与不可逆转换。
- 导入/导出、批量操作、分页、批量上限与稳定排序。
- 留存、法律保全、删除传播、匿名化与恢复的相互影响。
- 备份频率、完整性、加密、恢复演练、RPO/RTO 目标与归属。
- 错误记录的可审计性与更正。
- 数据血缘与外部处理方。

没有恢复证据就不要接受"备份存在"。不要因为迁移能在空的开发库上跑通就接受它。

## 并发、任务与分布式状态

评审：

- 共享可变状态、锁、事务、租约、比较并交换（CAS）与乐观并发。
- 竞态条件、重入、过期响应、重复提交与乱序完成。
- 队列投递语义、幂等、去重、毒消息与重新驱动。
- 重试分类、退避、抖动、上限、重试风暴与副作用安全。
- 取消、超时、任务清理、关停与在途工作。
- 调度器重叠、时钟偏移、领导者选举与漏跑/重复执行。
- 最终一致性、对账、冲突解决与用户可见的陈旧。
- 分布式事务、saga、补偿动作与部分失败。
- 背压、速率限制、队列增长、饱和与准入控制。
- 流/订阅生命周期与资源泄漏。
- 状态机清晰度与累积的布尔标志。
- 在不具备该能力的基础设施上宣称 exactly-once。

当非正式评审不够时，使用时序图、事件追踪、状态转换表、定向压力测试或基于模型的测试。

## 可靠性、运维与恢复

评审：

- 服务级指标/目标（SLI/SLO）或等效的可靠性目标。
- 错误预算或发布风险策略。
- 依赖地图与关键路径可用性。
- 超时、重试、熔断、舱壁、负载削减与优雅降级。
- 启动、就绪、健康、存活与关停行为。
- 关键工作流的日志、指标、追踪、仪表盘与告警质量。
- 黄金信号：延迟、流量、错误与饱和度（视情况适用）。
- 告警的可操作性、归属、路由、抑制与 runbook。
- 事故检测、分诊、缓解、沟通与复盘跟进。
- 备份、恢复、灾难恢复、故障转移、区域/账户恢复与演练。
- 降级模式、kill switch、功能停用与安全默认值。
- 队列恢复、卡死任务、对账与运维修复工具。
- 容量上限、配额、证书/域名到期与第三方故障。
- agent 可自主执行的运维变更。

验证恢复路径，而不仅是正常运行。没有负责人、告警或演练过的 runbook 的控制可能只是名义上存在而非真正有效。

## 发布、配置与变更安全

评审：

- 环境隔离与一致性。
- 配置来源、schema、默认值、校验、优先级与密钥分离。
- 特性开关的定向、失败行为、过期、清理与紧急停用。
- CI/CD 触发器、分支/tag 保护、审批、权限与职责分离。
- 构建、测试、工件晋级、发布签名、部署与回滚。
- 数据库/应用的先后顺序与混合版本兼容性。
- 金丝雀、分阶段发布、健康门禁、自动回滚与人工介入。
- 发布说明、迁移/运维指引与客户影响沟通。
- 不可变与可变工件，以及评审后被篡改的风险。
- 不可逆数据写入之后的回滚。
- 热修复与紧急破窗流程。
- 从源码到生产工件的可复现性与来源（provenance）。
- 生成的部署变更与基础设施漂移。

检查实际生效的工作流与权限，而不仅是 YAML 意图。

## 性能、容量与成本

评审：

- 工作负载假设、增长、峰值模式与服务上限。
- 算法复杂度与无界输入。
- 查询计划、N+1 访问、索引、分页与批量行为。
- 网络扇出、序列化、载荷大小、压缩与流式处理。
- 缓存行为、击穿防护与一致性成本。
- CPU、内存、文件描述符、连接数、线程/任务与存储增长。
- 冷启动、启动时间、客户端包/渲染与延迟预算。
- 背压、队列深度、准入控制与过载行为。
- 第三方配额、API 延迟、出口流量与成本。
- Agent/模型的 token 用量、上下文大小、重试、并行度、工具调用与"钱包耗尽"（denial-of-wallet）风险。
- 基准/负载测试的代表性回归阈值。
- 削弱正确性、安全或可运维性的性能优化。

发现须关联到现实的量级或观察到的行为。避免投机性的微优化。

## 供应链、构建与工件完整性

评审：

- 直接/传递依赖清单、归属、维护、支持与许可策略。
- Lockfile、vendoring、生成的代码、二进制、容器、action 与插件。
- 域名抢注（typosquatting）、依赖混淆、可变 tag、未固定来源与安装脚本。
- 漏洞监控、可达性、修复、例外与生命周期结束的运行时。
- 构建期网络访问与密闭性（hermeticity）。
- 源码控制保护与贡献者身份。
- CI runner、token 范围、密钥边界、缓存投毒与工件访问。
- 可复现/可追溯构建、来源证明、签名、校验和与 SBOM/清单。
- 工件晋级、制品库控制、不可变发布与回滚完整性。
- 生成器版本与更新路径。
- 第三方 MCP 服务器、技能、插件、agent 工具、远程指令与模型端点。
- AI 生成的复制代码的许可/安全影响。

把 SAST、依赖扫描、密钥扫描、来源证明、评审与运行时防御视为层层叠加的防线。没有任何单一工具能证明供应链安全。

## 测试、验证与评估

评审的是组合，而不仅是覆盖率百分比：

- 针对局部逻辑的单元测试。
- 针对数据、文件系统、网络、队列与服务契约的集成测试。
- 针对关键工作流的端到端/系统测试。
- 迁移、回滚、恢复、故障转移与灾难恢复测试。
- 权限、租户隔离、滥用与负向安全测试。
- 并发、重试、幂等与状态机测试。
- 风险需要时的性能、负载、浸泡与容量测试。
- UI/浏览器/无障碍/人工验证。
- 针对广泛不变量空间的属性、蜕变、差分、基于模型、模糊与混沌测试。
- 静态分析、类型、lint、密钥扫描、依赖扫描、SAST/DAST 与策略检查。
- 测试不稳定性、顺序依赖、环境漂移、fixture 真实性与数据污染。
- Mock 比例，以及 oracle 是否度量真实结果。
- CI 路径/分支覆盖与必需检查。
- 扫描器抑制与测试删除历史。

对 agent 系统还要评审：

- 能力与回归评测套件。
- 针对随机行为的多轮试验。
- 结果、转录/轨迹、工具调用、副作用、状态与人工校准评分器。
- 模型/harness 版本门禁与回滚信号。
- Reward hacking、基准泄漏、评分器操纵与捷径行为。
- 生产监控与反馈回路。
- 转录与评测数据的留存/脱敏。

一个通过的最终结果可能掩盖危险动作或对评审器的利用。对高影响 agent 要检查轨迹。

## 可维护性、归属与演进

评审：

- 模块/服务/数据归属与升级路径。
- 新人上手，以及意图能否从仓库本地来源恢复。
- 命名、注释、文档、ADR、图、契约与 runbook。
- 生成的文档与权威文档的区分，以及新鲜度强制机制。
- 复杂度/变动热点，以及没有任何维护者能解释的区域。
- 重复的辅助函数、平行抽象、不一致的模式与绕行路径。
- 公开 API 增长、扩展点、弃用与兼容性债务。
- 上帝模块、超长函数、深层分支、循环依赖与职责不清。
- 技术债条目、负责人、上限、触发条件与老化。
- 反复出现的事故/发现类别与缺失的持久控制。
- 团队巴士因子与隐性知识。
- Agent 可读性：地图、稳定的唯一事实来源、可预测的结构与工具可访问的证据。
- 下一次可能发生的变更是变得更容易还是更脆弱。
- 认知债务：代码产出速度超过人类/agent 的理解与掌控能力。

把可接受的局部复杂度与跨变更复利的结构性债务区分开。

## UI、无障碍与用户运营

评审：

- 信息架构，以及在累积变更中的一致性。
- 响应式布局、缩放、长文本/可翻译文本、RTL 与设备/浏览器支持。
- 语义化控件、键盘访问、焦点、标签、读屏行为、对比度与动效。
- 加载、空、错误、陈旧、禁用、提交中、选中、重试与离线状态。
- 破坏性操作、确认、撤销、范围可见性与恢复。
- 客户端/服务端校验一致性与安全的失败提示。
- 本地化、日期、数字、货币与复数形式。
- 乐观更新、重复操作、取消与过期响应处理。
- 运维/管理界面、批量操作、权限清晰度与审计追踪。
- 遥测/隐私影响与用户同意。
- 被脆弱的自定义控件取代的浏览器原生行为。

抽样真实工作流，而不仅是正常路径的截图。

## AI-Agent 仓库与运行时

当 agent 创建、评审、测试、部署或运维系统时，将其作为工程控制平面的一部分来审计。

评审：

- Agent/模型/harness 清单与版本/更新策略。
- Agent 身份、凭据、token 范围、吊销、网络访问、文件系统访问与沙箱配置。
- 针对生产、破坏性、特权、资金或数据导出操作的人工审批门禁。
- MCP 服务器、连接器、插件、hook、技能、浏览器工具、本地控制平面与远程行为。
- 来自 issue、PR、文档、网页、邮件、日志、工具输出、依赖与生成文件的提示注入。
- 不可信内容、控制指令与工具参数的分离。
- 在执行 shell、SQL、代码执行、部署或其他副作用之前对模型输出的校验。
- Agent 记忆、状态、进度账本、跨会话污染与投毒。
- 修改自身规则、权限、测试、扫描器或完成判据的能力。
- 无界循环、钱包耗尽、失控重试与 kill switch。
- 结果与轨迹可观测性；转录留存与密钥/PII 脱敏。
- 评测、模型升级门禁、回滚、人工校准与生产漂移。
- 同一模型兼任作者/评审者/修复者的相关性。
- 生成的依赖、代码来源、文档与测试有效性。
- 作为受维护的控制平面代码的仓库指令。

使用 `references/ai-agent-risk-catalog.md` 获取详细模式与证据策略。

## 反膨胀与简化

在范围内时，阅读 `references/anti-bloat.md` 并检查：

- 死代码、废弃的兼容路径、未使用的配置、投机性功能与陈旧的生成产物。
- 被自定义代码替代的标准库、框架、数据库、浏览器或平台能力。
- 价值不足以抵偿传递性/安全/运维成本的依赖。
- 单实现接口、单产品工厂、纯包装文件与只有一个调用方的层。
- 可以安全合并的重复状态、分支、文件或抽象。
- 应复用既有入口点的平行抽象。
- agent 生成的冗长与历次变更中的架构侵蚀。

按系统性收益对安全缩减排序，而不是原始删除行数。保留必要的控制、测试、无障碍、迁移、可恢复性与明确要求的行为。

## 抽样与证据

### 抽样信号

优先选择具备以下特征的区域：

- 高业务/安全/数据/可用性关键度。
- 高变动、高复杂度、归属更替或高缺陷密度。
- 广泛扇入/扇出或横切行为。
- 公开输入、特权操作或不可逆副作用。
- 薄弱的测试或可观测性。
- 新依赖、迁移、运行时/平台变更或 agent 工具链。
- 既往事故/发现，或接近触发条件的已接受技术债。
- Stale/Invalidated/Unknown 的覆盖状态。

### 证据层级

优先：

1. 复现的行为与当前运行时证据。
2. 针对当前 head/环境的可执行测试/检查。
3. 具体的代码/配置/数据流证据。
4. 权威的仓库文档/契约与经过验证的生成来源。
5. 版本控制历史与事故记录。
6. 供应商文档与标准。
7. Agent/人类的摘要，需要另行验证。

### 覆盖记录

对每个区域记录：

- 范围与边界。
- 质量属性/场景。
- 检查过的文件/接口/工作流。
- 命令与运行时证据。
- 发现与候选处置。
- 缺口与假设。
- 最近评审的提交/日期/环境。
- 依赖与失效触发器。
- 新鲜度状态与下次轮换原因。

不要用单一百分比概括异构的审计覆盖。
